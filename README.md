# LOST-FOUND
🔎 Lost & Found Management System

A simple C++ console-based Lost & Found Management System designed to maintain records of lost and found items.

📌 Project Overview

The system helps users record lost and found items, search for items, view all records, and update an item's status when it is returned.

This project demonstrates basic Object-Oriented Programming, File Handling, Vectors, Searching, Functions, and Conditional Statements in C++.

✨ Features

- ➕ Add Lost Item
- 📦 Add Found Item
- 📋 Display All Items
- 🔍 Search Items by Name or Category
- ✅ Mark Item as Returned
- 💾 Store records using file handling
- 🆔 Automatic Item ID generation
- 🖥️ Simple console-based interface

🛠️ Technologies Used

- Language: C++
- Concepts: OOP, Classes & Objects, Functions, Vectors, File Handling
- Compiler: GCC / MinGW
- Platform: Windows / Linux

▶️ How to Run

Step 1

Clone or download this repository.

Step 2

Open the project folder in Visual Studio Code or any C++ IDE.

Step 3

Compile the program:

g++ LostAndFound.cpp -o LostAndFound

Step 4

Run the program:

./LostAndFound

For Windows:

LostAndFound.exe
